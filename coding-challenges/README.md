# Singapore Coding Challenge: Merlion Munch

## Overview

For the Singapore event, we adapted the classic [Chomp!](https://github.com/gupta-kartik/chomp) maze game into **Merlion Munch**, a local take on the arcade-style chase game. Players guide a Merlion through a maze, collecting local food while avoiding pigeon chasers and taking on event-themed bonus challenges.

## Singapore-inspired game elements

- **Merlion player:** Replaces Chomp as the character, with a fish tail and animated water spout.
- **Laksa and kopi:** Laksa bowls and steaming kopi cups are collectibles worth 10 points each. Large laksa bowls act as power-ups.
- **Pigeon chasers:** Replace the original ghosts.
- **Singapore atmosphere:** A neon night-market look, Singlish reactions such as “Shiok!” and “Alamak!”, and glowing Supertrees on the start screen.

## Challenges and scoring

### Chope a table

Collect the pink tissue packet at the top-left of the maze, then reach the table at the bottom-right to earn **500 bonus points**. This mission can be completed once per level.

### Monsoon

An eight-second rainstorm slows the Merlion and pigeon chasers by **28%**. The event is announced with heavier rain, puddle splashes, lightning, thunder, and a “MONSOON!” banner.

### Haze bonus

An eight-second haze event adds drifting smoke and doubles the points earned from laksa and kopi. The effect is presented as a weather event.

## Event play

- **Move:** Arrow keys or WASD
- **Start:** Space
- **Pause:** P
- **Mute:** M

The Singapore version was developed as an interactive coding-showdown concept using GitHub Copilot. The game was later restored to the original Chomp version, so this document records the Singapore adaptation and challenge design rather than describing game files currently in this repository.
