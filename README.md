# Tech After Dark

**Tech After Dark** is a repeatable developer engagement program designed to create meaningful interactions between enterprise developers and GitHub’s platform in a relaxed, social setting.

Instead of traditional enterprise events, Tech After Dark combines **technical learning, friendly competition, and community** in an evening environment (typically a pub or casual venue). The goal is to create a memorable experience that drives developer enthusiasm, strengthens relationships with existing customers, and generates interest in GitHub’s enterprise capabilities.

This repository contains the **playbook and operational guide** for running a Tech After Dark event so that it can be replicated consistently across regions.

---

# Objectives

Tech After Dark aims to:

- Build stronger relationships with **enterprise developers**
- Increase awareness of **GitHub Enterprise, Copilot, and Advanced Security**
- Generate **qualified engagement and follow-up conversations**
- Create **memorable technical experiences** instead of passive presentations
- Provide a **repeatable event format** that can be run globally

---

# Event Format Overview

Typical duration: **2–2.5 hours**

The event alternates between **short talks and interactive segments** to keep energy high.

Example agenda:

| Segment | Description |
|-------|-------------|
| Welcome & Networking | Drinks, introductions, informal conversations |
| Talk 1 | Short talk on GitHub Enterprise capabilities |
| Quiz Round | Mentimeter fastest-finger-first quiz |
| Talk 2 | GitHub Copilot demo or AI-assisted development |
| Coding Showdown | Live Copilot coding challenge between participants |
| Talk 3 | GitHub Advanced Security |
| Quiz Round | Final trivia questions |
| Closing | Prize announcements, networking |

---

# Ideal Audience

- Enterprise developers
- Engineering managers
- DevOps engineers
- Platform engineers
- Security engineers
- Existing GitHub customers and prospects

Typical attendance: **30–60 participants**

---

# Venue Guidelines

Preferred venue characteristics:

- Casual environment (pub / brewery / social venue)
- Good audio setup
- Projector or large screen
- Reliable WiFi
- Space for networking and interaction
- Tables suitable for laptops (for coding showdown)

The goal is to **feel social rather than corporate**.

# Roles & Responsibilities

Running a successful Tech After Dark event requires a few clearly defined roles.

## Event Lead

Responsible for overall coordination.

Responsibilities:

- Venue coordination
- Agenda planning
- Speaker coordination
- Logistics and event flow

---

## Host / MC

Keeps the event energetic and moving.

Responsibilities:

- Opening the event
- Introducing speakers
- Running quiz rounds
- Managing audience engagement

---

## Technical Speakers

Present short technical talks.

Guidelines:

- Keep talks **10–15 minutes**
- Focus on **practical use cases**
- Avoid heavy product marketing
- Include demos where possible

Typical topics:

- GitHub Enterprise best practices
- Copilot workflows
- Secure development with Advanced Security

---

## Coding Showdown Judge

Responsible for:

- Preparing the coding challenge
- Evaluating submissions
- Explaining solutions

# Quiz Segment (Mentimeter)

The quiz segment is designed to energize the room and reinforce technical concepts.

Structure:

- 5–8 questions per round
- Fastest answer wins points
- Questions can include:
  - GitHub trivia
  - Software engineering concepts
  - Security questions
  - Copilot usage scenarios

Mentimeter is recommended because it allows:

- Real-time participation
- Leaderboards
- Easy audience interaction

Quiz templates will be added to this repository.

---

# Coding Showdown

The coding showdown is the highlight of the event.

Two participants compete to solve a programming challenge using **GitHub Copilot**.

## Format

- Two volunteers from the audience
- 10–15 minute challenge
- Participants project their screen
- Audience watches live

## Judging Criteria

- Correctness
- Code clarity
- Copilot usage
- Speed

## Example Challenge Ideas

- Parse and transform a JSON dataset
- Build a small API endpoint
- Implement a simple algorithm
- Write a test suite for existing code

Challenge templates will be stored in this repository.

# Event Preparation Checklist

## 4–6 Weeks Before

- Confirm venue
- Define agenda
- Identify speakers
- Prepare event page / registration

## 2–3 Weeks Before

- Prepare slides
- Create quiz questions
- Prepare coding challenge
- Order swag/prizes

## 1 Week Before

- Confirm attendance
- Test demos
- Test Mentimeter quiz
- Print event signage

## Event Day

- Arrive early
- Test AV setup
- Test WiFi
- Verify Mentimeter access
- Brief speakers and MC

---

# Post Event Follow-Up

Within 48 hours:

- Send thank-you email
- Share slides and resources
- Connect with attendees on LinkedIn
- Identify follow-up opportunities

Possible follow-ups:

- Product demos
- Copilot trials
- Security workshops
- Architecture discussions
